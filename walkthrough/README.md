# 27PR · 走进家里（自由漫游）

实时网页漫游版，和同仓库根目录的 CGI 相册并行存在，互不替代：
相册是离线渲染的定版画面，这里是可以自己走动、开门的实时版本。

在线地址：https://icebbay.github.io/27pr-cgi/walkthrough/

## 操作

- WASD / 方向键行走，Shift 快走。
- 点击画面后移动鼠标环顾，Esc 释放鼠标。
- 看向附近的门，按 E 或点击屏幕提示开门 / 关门。
- V 或顶部按钮切换第一人称 / 跟随人物。
- 房间导航可直接前往 19 个位置，也能沿走廊和楼梯连续走到。
- 触屏：左下方向键移动，拖动画面转头，点击门提示开关门。

## 范围

23 个可交互门扇，包括室内平开门、双开玻璃门、折叠门和推拉门。
人物与墙体、家具、门之间有碰撞处理；关门时人物挡住门会停止开合。
电梯升降、柜门和抽屉不在本轮交互范围内。
网页保留家具与材质贴图，照明是实时近似，和离线渲染相册不会完全一致。

## 部署

纯静态目录，直接由 GitHub Pages 提供。
本地预览需要通过一个静态服务器打开本目录（浏览器不能用 file:// 加载三维模型）。
三维库已随目录附带，不需要联网下载。第三方许可见 vendor/THREE-LICENSE.txt。

模型由已确认的 27PR_CGI_v6 场景导出，导出过程不修改源 .blend 文件。

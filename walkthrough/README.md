# 27PR · 走进家里（自由漫游）

实时网页漫游版，和同仓库根目录的 CGI 相册并行存在，互不替代：
相册是离线渲染的定版画面，这里是可以自己走动、开门、操作家具的实时版本。

在线地址：https://icebbay.github.io/27pr-cgi/walkthrough/

## 操作

- WASD / 方向键行走，Shift 快走。
- 点击画面后移动鼠标环顾，Esc 释放鼠标。
- 看向附近的门，按 E 或点击屏幕提示开门 / 关门。
- 看向家具的活动部分（抽屉、柜门、升降桌与梳妆台、转椅的靠背/头枕/扶手、屏风面板、毛巾杆、床板等），按 E 或点击提示操作，再按一次复位。
- V 或顶部按钮切换第一人称 / 跟随人物。
- 房间导航可直接前往 19 个位置，也能沿走廊和楼梯连续走到。
- 触屏：左下方向键移动，拖动画面转头，点击提示开关门或操作家具。

## 范围

17 扇可交互门（室内平开门、外开法式门、推拉门、主厅吸音墙隐形门）和 90 个家具活动件。
2026-10-06 起（v40）：二层后房间改为卧室 4 + 东侧套内卫生间（卫生间门开在隔墙南段、向卧室开），卧室 2 进门挪到北墙西端（门东侧铰链、向内开），两扇门都能开关、人物能走过；房间导航「后卧室」「后卧室套卫」。
2026-10-03 起（v38）门按最新户型：二层后卫生间门（东侧铰链，开向书房）、洗衣房后门改单扇（左铰，向后花园外开）、二层书房门改东侧铰链，三扇都能开关、人物能走过。
后院三对外开法式门可开到 95°，人物能直接走到后院露台。
人物与墙体、家具、门之间有碰撞处理；关门时人物挡住门会停止开合。
家具活动件不参与碰撞；电梯升降不在交互范围内。
2026-10-07 起恢复昼夜和灯光：右上角按钮或 N 切换 早晨 / 中午 / 傍晚 / 夜晚。墙上开关接的就是照明施工图（Rev I）里的灯：看向开关，单键按 E，多键按数字键 1–4（手机点屏幕下方的键）；双控 / 三控、楼梯一楼二楼三控都和施工图一致（59 盏灯、29 个开关、57 个键逐个测过）。后花园新增投光灯（SOLLA 三头 150W，两扇后门中间、离地约 3.5 m）。

## 部署

纯静态目录，直接由 GitHub Pages 提供。
本地预览需要通过一个静态服务器打开本目录（浏览器不能用 file:// 加载三维模型）。
三维库与 Draco 解码器已随目录附带，不需要联网下载。第三方许可见 vendor/THREE-LICENSE.txt。

2026-10-06 起模型由 27PR_CGI_v40_bed2_door_20261006 导出（v38 之后：后卧室 4 + 套卫、卧室 2 进门西移、一层后花园新壁灯 G26_4）；电脑版约 13.2 MB、手机版约 11.0 MB。
2026-10-03 起模型由 27PR_CGI_v38_door_hinges_20261003 导出（v19 之后：起居室→餐厅门洞梁托小拱、后花园角落假山跌水 8 字形鱼池、二楼后书房 / 卫生间换格局、厨房东墙柱子 600 深，以及上述门铰链）；电脑版约 13.4 MB、手机版约 11.2 MB：手机版的水景简化（松针只留 1/5，跌水 / 假山 / 松树皮等大件每件减到 3000 面以内，鱼池、长凳、锦鲤不动），墙面开关插座按原来的规则减面（电脑版也是）。
2026-09-28 的 v19 由 27PR_CGI_v19_integrated_materials 导出：墙体/楼板/天花按层合并、缝隙闭合、新的后院露台与草坪、沙发按色卡 TC-28。
模型用 Draco 压缩几何、WebP 贴图，同一件物体的静态零件合并；电脑版约 10.7 MB、手机版约 9.3 MB（v16 为 38.6 / 28.3 MB）。
椅子和凳子不再减面（此前手机版吧椅被减碎）。导出过程不修改源 .blend 文件。

# 27PR · 走进家里（自由漫游）

实时网页漫游版，和同仓库根目录的 CGI 相册并行存在，互不替代：
相册是离线渲染的定版画面，这里是可以自己走动、开门、操作家具的实时版本。

在线地址：https://icebbay.github.io/27pr-cgi/walkthrough/

## 操作

- WASD / 方向键行走，Shift 快走。
- 点击画面后移动鼠标环顾，Esc 释放鼠标。
- 看向附近的门，按 E 或点击屏幕提示开门 / 关门。
- 看向家具的活动部分（抽屉、柜门、升降桌与梳妆台、转椅的靠背/头枕/扶手、屏风面板、毛巾杆、床板等），按 E 或点击提示操作，再按一次复位。
- V 或顶部按钮切换第一人称 / 跟随人物。
- 顶部时段按钮或 N 键：早晨 / 中午 / 傍晚 / 夜晚。房子前门朝西、后院朝东：早晨阳光从东边后院进来，中午在南，傍晚从西边前门一侧进来（按英国约北纬 54° 设定）。电脑版有实时太阳阴影。
- 傍晚和夜晚灯会亮；看向墙上的开关按 E 开关这个房间的灯。没接开关的灯（室外灯、楼梯吊灯等）看着灯按 E。
- 房间导航可直接前往 19 个位置，也能沿走廊和楼梯连续走到。
- 触屏：左下方向键移动，拖动画面转头，点击提示开关门或操作家具。

## 范围

19 扇可交互门（室内平开门、外开法式门、推拉门、主厅吸音墙隐形门），另有 90 个家具活动件，包括 F25 一门两用门、F26/F27 PD 门；27 盏灯、21 个墙面开关（开关与灯的对应按房间推断，待确认）。
人物与墙体、家具、门之间有碰撞处理；关门时人物挡住门会停止开合。
家具活动件不参与碰撞；电梯升降不在交互范围内。
网页保留家具与材质贴图，照明是实时近似，和离线渲染相册不会完全一致。
